# Kumanda

Windows için Kumanda (eski adıyla Claude Terminal) kurulum dosyaları ve otomatik güncellemeler.

**İndir:** [Releases](https://github.com/atakansensoy/claude-terminal/releases/latest) sayfasından `Kumanda-Kurulum-x.y.z.exe` dosyasını indirip çalıştır. Uygulama kurulduktan sonra yeni sürümleri kendisi indirir ve kurar.

Bu depoda yalnızca kurulum dosyaları yayınlanır.
